## [v0.16.7] - 2026-08-10

### 新功能
- 新增「中国移动云盘（139）上传」：上传队列目标为 139 时自动按文件 SHA256 秒传，未命中走 100MB 分片上传（/file/create → getUploadUrl → 分片 PUT → complete），上传进度实时更新
- 新增「139 分享转存」：文件管理器工具栏「保存分享」（139 账号显示），粘贴分享链接自动解析提取码，浏览分享目录勾选文件/目录转存到当前目录，转存后自动刷新列表（POST /api/pan139/share/info、POST /api/pan139/share/save）
- 139 网盘支持重命名、移动、目录整理（此前返回"暂不支持"）
- 跨盘秒传目标支持 139：无本地文件时自动入队中转，上传阶段按 SHA256 自动秒传
- 139 删除改为异步任务提交（batchTrash 返回 taskID）

### 说明
- 跨盘秒传目标 139 指纹未命中时走中转上传（与光鸭一致），不占用源网盘流量；139 秒传需完整文件 SHA256，跨盘场景无法预判，由上传阶段自动命中
- 139 分享转存任务无状态查询接口，提交后轮询目标目录验证完成（最多 20 秒），超时任务仍在后台执行
