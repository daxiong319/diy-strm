## [v0.16.0] - 2026-08-08

### 新功能
- 接入 123 云盘：逆向 API 客户端（登录/列表/下载/上传/删除）、STRM 同步驱动、直链播放与登录状态路由、前端授权对话框
- 接入光鸭云盘：支持短信验证码/扫码/令牌三种授权方式，同步入口优先使用保存的目录 ID
- 接入中国移动云盘（139）：支持扫码登录自动获取 Authorization 凭据、STRM 同步与直链播放
- 123 云盘令牌自动重登录持久化、下载直链优先、并发登录保护与上传分片进度修正

### 修复
- 修复移动云盘（139）STRM 播放失败与嵌入式 PostgreSQL 误杀问题
- 前端 CSRF 适配：登录响应解析并持久化 csrf_token，axios 请求拦截器自动附加 X-CSRF-Token 头
- 日志/事件流 WebSocket 迁移至 SSE，修复事件推送丢失
- account 表 token/refresh_token 字段扩宽至 4096，修复光鸭/123 云盘登录保存凭据失败
- source_type 白名单补充 guangyapan，修复添加同步目录/选择目录报错；加固相对路径校验
- 新增 /sync/path-add 与 /sync/path-update 兼容路由

### CI
- 发布流程接入 DockerHub 自动推送（afengj/diy-strm），GHCR 推送保留
- 修复失效的 docker/source.Dockerfile 路径，改用根目录 Dockerfile 全量构建
